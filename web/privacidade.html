Política de Privacidade

Esta interface foi criada para consultar informação do SIGARRA e manter o histórico de conversa. O objetivo desta página é explicar, de forma simples, que dados são tratados e para que servem.

Dados que a aplicação trata

  • Mensagem que o utilizador escreve na conversa.
  • Respostas geradas pelo sistema e respetivas fontes.
  • Identificador técnico do browser para manter a sessão.
  • Informação de autenticação SIGARRA apenas durante a sessão ativa.
  • Métricas de utilização, como tempo de resposta e feedback dado às respostas.

O que não é guardado

  • Passwords SIGARRA em texto simples na base de dados.
  • Dados desnecessários para o funcionamento do assistente.
  • Informação pessoal fora do contexto de utilização do assistente.

Finalidades do tratamento

  • Responder às perguntas do utilizador.
  • Manter conversas separadas por conta autenticada.
  • Melhorar a qualidade das respostas e a manutenção técnica.
  • Produzir métricas internas de uso e desempenho.

Base de funcionamento

O sistema precisa de tratar estes dados para prestar o serviço, manter a sessão e mostrar o histórico. O acesso administrativo está protegido por password.

Se este projeto for usado numa publicação oficial, recomenda-se validação final com a instituição responsável antes de disponibilizar ao público.
